# Sistema de Casa de Leilões - LeiloesTDSat

## Sobre o Projeto

Este projeto consiste em um sistema informatizado desenvolvido para gerenciar e otimizar as rotinas e processos diários de uma casa de leilões. O software foi estruturado com foco na segurança das operações, integridade dos dados e qualidade no gerenciamento de produtos e lances.

## Tecnlogias Utilizadas

* **Java** (Linguagem de desenvolvimento de sistemas)
* **MySQL** (Sistema de Gerenciamento de Banco de Dados - SGBD)
